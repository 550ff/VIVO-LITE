# VIVO-LITE V1.3 platform notes

The V1.3 implementation keeps the launcher on native Views and APIs available on API 22. The visual direction uses restrained translucent surfaces and short touch feedback; it does not attempt continuous blur or OEM system overlays. References informed interaction goals only and are not copied assets or layouts.

## Platform decisions

- Native widgets use `AppWidgetHost` / `AppWidgetHostView`; the host starts and stops listening with the Activity lifecycle. Widget configuration and host IDs are kept by Android and launcher preferences respectively. Resizing is a best-effort host size hint because providers may ignore it.
- Icon packs use the ADW/Nova `appfilter.xml` static component mapping convention. Mapped pack icons keep their original colour; unmapped system icons retain the VIVO-LITE monochrome treatment.
- Wi-Fi and Bluetooth use API 22 platform controls where allowed; brightness requests write-settings access on API 23+ and falls back to Android display settings when access is not granted. The flashlight uses Camera1 because CameraManager is API 23+.
- Notification access is optional and may be unavailable on low-RAM devices running Android Q or earlier. VIVO-LITE must show the existing unavailable/disconnected state instead of synthesizing notifications.
- The Pulse capsule reports battery/charging state only. Smart Edge delegates timer setup to Android Clock and provides a local calculator intent, saved note, and favourites; it does not claim system-wide activity tracking.
